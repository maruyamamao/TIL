# 経営戦略
- 企業理念に基づいて企業の経営目的を達成するために立案する戦略
- 経営戦略の中で最上位に位置するのが**経営革新**

## 経営革新
- 企業がそれまでの方向性を見直して新たな企業活動に取り組む戦略

### 経営革新の考え方
- **ベンチマーキング**
→ 最強の競合相手、先進企業と自社の経営を比較して製品、サービス、オペレーションなどを定性的・定量的に把握すること、ベストプラクティスとの**比較分析**から**自社の経営革新に役立てる**
- 多角化
→それまでの製品や市場と異なる新たな分野に進出することによって事業を成長させようという経営革新、**シナジー効果(相乗効果)を期待できる**

|名称|期待するシナジー効果|
|-|-|
|販売シナジー効果|物流などの流通チャネルやブランドイメージなどを共有する、販売活動に関する効果|
|生産シナジー効果|施設や人材の共有、現在りょの一括大量購入などにより、生産活動のコストを低減する効果|
|投資シナジー効果|施設や設備、及び新製品の開発・研究費など様々な投資を低減する効果|
|経営シナジー効果|経営者などの経験、知識やノウハウを共有することにより得られる経営活動に関する効果|

# 全社戦略
- 企業理念や経営ビジョンに従って企業全体として経営の方向性を示すために立案する戦略
- 市場における自社の**地位を競争地位分析**によって求める

## 競争地位分析
- 投資する経営資源の質と量により、市場での地位を分析する手法、自社の地位を分析する

|相対的||量||
|-|-|-|-|
|経営資材||多い|少ない|
|質|高い|**リーダ**|**ニッチャ**|
||低い|**チャレンジャー**|**フォロワー**|
- リーダー
→ 経営資源が量・質ともに優れている、業界のシェア1位の地位、最大シェアを確保する**全方位戦略**をとる

- チャレンジャー
→ 経営資源が量的には優れているが、質的にはリーダーに劣っている、業界のシェア2～4位の地位、リーダーを狙う地位にあり、シェア追撃などのリーダ攻撃に必要な**差別化戦略**をとる

- ニッチャ
→ 経営資産が質的には優れていため、特定市場(製品)で優位に立っているが量的にはリーダーに夫ている地位、最初から顧客のニーズが満たされていない以上の**すきま**を狙って事業を展開し、特定事業のニッチャを目指す**ニッチ戦略**をいう考え方もある

- フォロワー
→ 経営資材が量・質ともにおとっているため**リーダに追従する地位**、リーダーの製品を模倣しつつ、コストダウンによる低価格化などで市場チャンスに素早く対応する**模倣戦略**をとる

- コアコンピタス経営
→ 他社よりも優越した**自社独自の技術やノウハウ(コアコンピタンス)**に経営資源を集中投下する経営

## アライアンス
- 複数の企業間で相互協力体制を作ること、アライアンスは提携のこと

- **M&A**
→ 買い付け価格と期間を公表して不特定数の株主から株式を購入する**TOB：株式公開買い付け**などを利用した株式取得などにより他社を吸収・支配する最も強いアライアンス、合併・買収先企業の同意を得ずに行われる敵対的M&Aに対してはMBO：経営陣により自社買収などの対策が取られることもある

- **垂直統合/水平統合**
→ 製造から販売までの工程の範囲を広げる垂直統合と同じ工程を他企業を取り込む水平統合がある、生産量が増加すると単位当たりの総コストが減少することから生産量増加によって利益率を向上させる規模の経済のアライアンスとなる

## アウトソーシング
- 自社の特定事業を外部企業に委託すること

### アウトソーシングの形態
- **ファブレス**
→ 自社では工場をを持たずに製品の規格だけを行い他社に出遺産を委託する形態である委託された企業が相手先の商標やブランドで製造・供給することをOEMといい、他社から受注した電子機器などの受託生産を行うことをEMSという
- **オフショアアウトソーシング**
→ 物価・人件費の安い海外企業に事業を委託する形態

- **PPM(プロダクトポートフォリオマネジメント)**
→ 市場成長率と市場占有率の関係から事業や製品の特性と分析する手法、PPMマトリックスで特性を分析する
