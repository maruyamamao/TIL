# 最大値
- データの中から最大値を見つけるアルゴリズム
- 「現在の最大値」と「読んだデータ」を比較する

```:例
〇整数型: ex_1(整数型の配列: T, 整数型: N)
整数型: Max, i, Midx

Max ← T[0]
i ← 1
Midx ← 0  // 現在の最大値の添え字を代入

while(iがNより小さい)
  if(T[i]がMaxより大きい)
    Max  ← T[i]
    Midx  ← i
  endif
  i  ← i + 1
endwhile

return Midx  // 最大値の添え字を返す
```

# 最小値
- データの中から最小値を見つけるアルゴリズム
- 「現在の最小値」と「読んだデータ」を比較する

```:例
〇整数型: ex_2(整数型の配列: T, 整数型: N)
整数型: Min, i, Midx

Min ← T[0]
Midx ← 0  // 現在の最小値の添え字を代入

for(iを1からN - 1まで1ずつ増やす)
  if(T[i]がMinより小さい)
    Min ← T[i]
    Midx ← i
  endif
endfor

return Midx  // 最小値の添え字を返す
```

# 線形探索
- 一致するまで探索するアルゴリズム

```:例1
整数型: ex_1(整数型: X, 整数型の配列: T, 整数型: N)
整数型: i

for(iを0から N - 1まで1ずつ増やす)
  if(T[i]がXと等しい)
    return i         // 探索が成功したらその値の添え字を返す
  endif
endfor

return -1           // 探索失敗
```

```:例2
整数型: ex_2(整数型: X, 整数型の配列: T, 整数型: N)
整数型: i ← 0

while(iがNより小さい) and (T[i]がXと等しくない)
  i ← i + 1
endwhile

if(iがNより小さい)
  return i         // 探索が成功したらその値の添え字を返す
else
  return -1        // 探索失敗
endfor         
```
