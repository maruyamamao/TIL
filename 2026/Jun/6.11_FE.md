# 情報セキュリティマネジメントシステム(ISMS)
→組織が自身の情報資産を適切に管理し、それらを守るための仕組み
- PDCAサイクル
  - Plan:計画 → Do:実行 → Check:点検 →  Act:処置

- プライバシーポリシー
  - 企業活動の情報セキュリティ諸規定の１つ
  - 近年重要視されている
  - 氏名や生年月日など、個人を特定できる情報を保護
  - プライバシーマーク制度
    - 個人情報の取り扱いについて適切な保護措置を講じる体制を整備している民間事業者などを認定する制度
    - 認定された事業者はプライバシーマーク(Pマーク)が付与される 

# 情報セキュリティ
- 情報の「機密性」、「完全性」、「可用性」を維持すること
- 情報セキュリティの目的は３要素の維持 

## 情報セキュリティの3要素
- 3つの特性(CIA)

|名称|英語|意味|補足|例|
|-|-|-|-|-|
|機密性|**C**onfidentiality|許可された人だけが情報にアクセスできるようにし、情報が漏洩しないようにすること|秘密を守る・盗聴を防ぐ|暗号化・アクセス制限など|
|完全性|**I**ntegrity|情報が書き換えられたりすることなく、完全な状態を保っている状態にすること|改ざんを防ぐ|ハッシュ化|
|可用性|**A**vailability|利用者が、必要な時に必要な情報資産を利用できる状態にすること|いつでも使える|二重化|


# 情報セキュリティの７要素(３要素 + 4要素)
- 情報セキュリティの３要素に「真正性」、「責任追及性」、「否認防止」、「信頼性」を追加したもの

|名称|英語|意味|
|-|-|-|
|真正性|Authenticity|利用者は主張した通り本物であるということ|
|責任追及性|Accountability|利用者やアクセスなどが一意に追跡できること|
|否認防止|Non-Repudiation|主張された事象や処置の発生、それらを引き起こした利用者を証明すること|
|信頼性|Reliability|意図する行動と結果が一貫しているということ

# 情報セキュリティの管理対象
→悪意の持った侵入者は**脆弱性**という穴を探し、その**脅威**に対して企業がもつ情報**資産**を守ることが管理対象

|名称|英語|意味|例|
|-|-|-|-|
|資産|asset|組織にとって価値を持つもの<br>情報資産、守るべき価値のあるもの|有形情報資産：ハードウェア、ドキュメント、人的資産など<br>無形情報資産：ソフトウェア、顧客情報、知的関連財産情報など|
|脅威|threat peril|システム又は組織に損害を与えるインシデントの潜在的な原因、資産に損害を与える可能性があるもの|物理的脅威：災害、不正侵入など<br>人的脅威：情報漏洩、誤操作、不正利用など<br>技術的脅威：不正アクセス、クラッキングなど|
|脆弱性|vulnerability hazard|1つ以上の脅威によって付け込まれる可能性のある資産または管理策の弱点|設備面：建物への侵入、施錠管理など<br>技術面：パスワード、ウィルス対策など<br>管理面：ユーザ教育、マニュアルなど|

## 情報セキュリティの管理機能
→ 情報セキュリティの３要素を維持するための５つの管理機能
- 予防機能 → 脅威の発生を未然に防ぐ
- 抑止機能 → 脅威を発生させる行為をけん制する機能
- 検知機能 → 脅威を発生させる行為者を発見・検出する機能
- 最小化機能 → 発生した驚異の被害を最小限に抑え、拡大を防止する機能
- 復旧機能 → 脅威による被害を速やかに復旧する機能
