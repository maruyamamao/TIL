# while文
→ 条件が成り立っている間処理を繰り返し実行する制御文、カウンタにあたるものがないため宣言しないといけない、先に条件を評価するため1回も処理を実行しない場合がある
```:while文
while(条件式)
{
処理
}
```
```c#:例：1回は実行される場合
// 1から10まで加算
int Sum = 0;
int i = 1;

while(i <= 10)
{
Sum += i;
i++;
}

// 55が出力される
Console.WriteLine(Sum);
```
```c#:例：1回も実行されない場合
// 10から1まで加算
int Sum = 0;
int i = 10;

while(i < 10)
{
Sum += i;
i++;
}
// 0が出力される
Console.WriteLine(Sum);
```

# do while文
→ while文と同じように繰り返しを行う制御文、カウンタにあたるものがないため宣言しないといけない、条件式を下に書くため1回は処理が実行される
```:do while文
do{
処理
}while(条件式)
```
```c#:例：繰り返し実行される場合
// 1から10まで加算
int Sum = 0;
int i = 1;
do
{
 Sum += i;
 i++;
}while (i <= 10);
// 55が出力される
 Console.WriteLine(Sum);
```
```c#:例：1回は実行される場合
// 10から1まで加算
int Sum = 0;
int i = 10;
do
{
 Sum += i;
 i++;
}while (i < 10);
// 10が出力される
 Console.WriteLine(Sum);
```
