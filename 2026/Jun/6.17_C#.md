# for文
→ 繰り返し処理を効率よく行うための制御文、カウンタを宣言しながら条件式が書ける
```:for文
for(カウンタ変数; 条件式; カウンタ増減;)
{
処理
}
```
```c#:例
// 1から100まで加算
int Sum = 0;
for(int i = 1; i <= 100; i++)
{
Sum += i;
}
// 5050が出力される
Console.WriteLine(Sum);
```

# 2重ループ(ネスト)
→ 繰り返し分を二重ループすることで複雑な処理を実行できる
```c#:例
 for(int i = 0; i < 6; i++)
 {
     for(int j = 0; j < 10; j++)
     {
         if(i % 2 == j % 2)
         {
             Console.Write("□");
         }
         else
         {
             Console.Write("■"); 
         }
     }
     Console.WriteLine();
 }

```
