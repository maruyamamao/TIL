# break文
→ 繰り返しを途中で中断して1番近いブロックにジャンプする
```C#:例: while文
// 1から10まで加算
int i = 1;
int Sum = 0;
while(i <= 10)
{
  if (i == 5)
  {
    Console.WriteLine("iが５なので中断しました。");
    break;
  }
  Sum += i;
  i++;
}
// 10が出力
// 1から4までしか加算されていない
Console.WriteLine($"合計は{Sum}です。");
```

```C#:例: do while文
int i = 1;
int Sum = 0;
do
{
  if (i == 5)
  {
    Console.WriteLine("iが５なので中断しました。");
    break;
  }
  Sum += i;
  i++;
}while(i <= 10)
// 10が出力
// 1から4までしか加算されていない
Console.WriteLine($"合計は{Sum}です。");
```

```C#:例: 
int Sum = 0;
for(int i = 1; i <= 10; i++)
{
  if (i == 5)
  {
    Console.WriteLine("iが５なので中断しました。");
    break;
  }
  Sum += i;
}
// 10が出力
// 1から4までしか加算されていない
Console.WriteLine($"合計は{Sum}です。");
```

# continue文
→ その処理を中断して、1番近いループの始まりに戻る。
```c#:while文
int i = 1;

while(i <= 3)
{
  if (i == 2)
  {
    i++;
    continue;
  }
  Console.WriteLine($"iの値は{i}です。");
  i++;
}

// iの値は1です。
// iの値は3です。
```

```c#:do while文
int i = 1;

do
{
  if (i == 2)
  {
    i++;
    continue;
  }
  Console.WriteLine($"iの値は{i}です。");
  i++;
}while(i <= 3)

// iの値は1です。
// iの値は3です。
```

```c#:for文
for(int i = 1; i <= 3; i++)
{
  if (i == 2)
  {
    continue;
  }
  Console.WriteLine($"iの値は{i}です。");
}

// iの値は1です。
// iの値は3です。
```
