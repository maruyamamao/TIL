# 配列
→ 複数の同じ型の変数を1つにまとめたもの、大量のデータを扱うときや複数のデータを自動的に読みだしたしたい時に使用すると便利、数値以外の文字も格納できる
```
int [] a = new int [4];
 ↑     ↑        ↑   ↑
型  配列名      型  要素数
```
- 宣言と同時に初期化する場合
```c#:例
int [] b = {1, 2, 3, 4, 5};
```
- 要素を参照するときは添え字で参照する、0から始まるので注意
```c#:例
int [] c = {1, 3, 6, 4, 0};
Console.WriteLine(c[0]); // 1
Console.WriteLine(c[3]); // 4
```
- 代入する場合も添え字を使用する
```c#:例
int [] d = {1, 3, 6, 4, 0};
d[0] = d[4];
d[3] = d[2];

Console.WriteLine(d[0]); // 0
Console.WriteLine(d[3]); // 6
```

- 繰り返し分を使用すると効率よく処理できる
```c#:例
string [] enemy = {"スライム", "ゴジラ", "魔王", "魔法使い", "エルフ", "ドラゴン", "デビル"};

for(int i = 0; i < enemy.Length; i++)
{
  Console.WriteLine($"{enemy[i]}が現れた！");
}

/*
スライムが現れた！
ゴジラが現れた！
魔王が現れた！
魔法使いが現れた！
エルフが現れた！
ドラゴンが現れた！
デビルが現れた！
*/
```

# foreach文
→ 複数のデータの集まりの各要素を最初から最後まで1回ずつ呼び出して処理する、for文などよりもシンプル繰り返し処理をかける
```
   要素の型 変数名 配列名
         ↓  ↓      ↓
foreach(int a in nums)
{
  処理
}
```

```c#:例
string [] enemy = {"スライム", "ゴジラ", "魔王", "魔法使い", "エルフ", "ドラゴン", "デビル"};

foreach(string ene in enemy)
{
  Console.WriteLine($"勇者一行が{ene}を討伐した！");
}

/*
勇者一行がスライムを討伐した！
勇者一行がゴジラを討伐した！
勇者一行が魔王を討伐した！
勇者一行が魔法使いを討伐した！
勇者一行がエルフを討伐した！
勇者一行がドラゴンを討伐した！
勇者一行がデビルを討伐した！
*/
```
