# 関数(function)
- 別のプログラムを呼び出すことができる
- 呼び出し側のプログラムは引数(処理に必要なデータ)を渡すことができる
- 呼び出されたときに処理結果を戻り値(返却値)で呼び出し側に返す
- 戻り値をもたないものを手続と呼ぶ


```:例1
〇整数型: ex_1(整数型: A)
if(Aが0より大きい)
  return A
else
  return A * (-1)
endif


ex_1(4)として呼び出した場合の返却値
⇒ 4

ex_1(-2)の時のとして呼び出した場合の返却値
⇒ 2
```

```:例2
〇整数型: ex_2(整数型: A, 整数型: B)
整数型: C ← 0
while(AがBより大きい)
  C ← C + A
  A ← A - 1
endwhile
return C


ex_2(7, 2)として呼び出した場合の返却値
⇒ 25

ex_2(4, 8)として呼び出した場合の返却値
⇒ 0
```

```:例3
〇整数型: ex_3(整数型: A)
return MyFunc(A * 2) + 3

〇MyFunc(整数型: A)
return A - 1


ex_3(1)として呼び出した場合の返却値
⇒ 4

ex_3(5)として呼び出した場合の返却値
⇒ 12
```

```:例4
〇整数型: ex_4(整数型: A)
整数型: B, C
MyFunc(A, B, C)
return B * 10 + C

〇MyFunc(整数型: X, 整数型: Y, 整数型: Z)
Y ← X mod 10
Z ← X / 10


ex_4(47)として呼び出した場合の返却値
※MyFuncのYとXは出力用の変数とする
⇒ 74

ex_4(85)として呼び出した場合の返却値
※MyFuncのYとXは出力用の変数とする
⇒ 58
```

# 大域変数
- 複数のプログラムが参照できる変数

```:例1
大域: 整数型: X
〇整数型: ex_11(整数型: A)
X ← 1
A ← MyFunc(A)
Xを出力

〇整数型: MyFunc(整数型: B)
X ← 2
return B * 2


ex_11(1)として呼び出した場合の返却値
⇒ 2

ex_11(3)として呼び出した場合の返却値
⇒ 2
```

```:例2
大域: 整数型: X
〇整数型: ex_12(整数型: A)
整数型: B
B ← A + 1
X ← B * 2
A ← MyFunc(A)
Bを出力

〇整数型: MyFunc(整数型: A)
整数型: B
B ← X
X ← A
return B + 1

ex_12(1)として呼び出した場合の返却値
⇒ 2
```
