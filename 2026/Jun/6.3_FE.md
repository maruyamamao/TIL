## for文
→ while文などのような繰り返し処理をしたい時にしようする
```
for(制御記述)
  繰り返す処理
endfor
```
```:例
for(Iを1から5まで1ずつ増やす)
  Iを出力
endfor

・ Iを1で初期化
・ I = 1を出力
・ Iを1増やして、2とする
・ I = 2を出力
・ Iを1増やして、3とする
・ I = 3を出力
・ Iを1増やして、4とする
・ I = 4を出力
・ Iを1増やして、5とする
・ I = 5を出力
・ループを抜ける
```

→ 繰り返し処理を使うとプログラムを簡潔に示すことができる
```:1から100までの整数の合計
整数： Total ← 0
for(iを1から100まで1ずつ増やす)
Total ← Total + i
endfor
```

## for文のネスト
```:例 九九
for(iを１から9まで1ずつ増やす)
  for(jを１から9まで1ずつ増やす)
    i ×　jを出力
  endfor
  改行を出力
endfor
  
```
