## if文
→ 条件によって、実行する処理を分けるときに使用
→ 条件が成立した場合は処理１を実行し、成立しなかった場合は処理２が実行される
```:例
if(条件式)
　処理１
else
  処理2
endif
```

## 複合条件
→ 複数の条件を **and** や **or** で結んだもの

### and の場合
→ 条件１と条件２が満たされた時のみ**ture**になり、どちらかの条件が満たされなかった時は**false**になる
|Trueになる場合|||Falseになる場合||
|-|-|-|-|-|
|条件1|条件2||条件1|条件2|
|〇|〇||〇|✕|
|ー|ー||✕|〇|
|ー|ー||✕|✕|
```:例
整数型：A, B
A ← 10
B ← 100

if ((A mod 2)が0と等しい) and ((B mod 2)が0と等しい)
  "AとBは偶数です。"
else
  "AとBは奇数です。"
endif

⇒ AとBは偶数です。が出力される
```

### or の場合
→ 条件１と条件２が満たされた時と、条件のどちらかが満たされたときに**true**になり、どちらも満たされなかった時に**false**になる
|Trueになる場合|||Falseになる場合||
|-|-|-|-|-|
|条件1|条件2||条件1|条件2|
|〇|〇||✕|✕|
|〇|✕||ー|ー|
|✕|〇||ー|ー|
```:例
整数型：A, B
A ← 11
B ← 100

if ((A mod 2)が0と等しい) or ((B mod 2)が0と等しい)
  "AとBどちらかが偶数です。"
else
  "AとBは両方とも奇数です。"
endif

⇒ AとBどちらかが偶数です。が出力される
```

## 多分岐
→ 3つ以上の分岐先が分かれる分岐の構造で、**elseif** を使用する

```:例
整数型：A, B
A ← 11
B ← 100

if ((A mod 2)が0と等しい)
  "Aが偶数です。"
else if ((B mod 2)が0と等しい)
  "Bが偶数です。"
else
  "AとBは両方とも奇数です。"
endif

⇒ Bが偶数です。が出力される
```

## if文入れ子(ネスト)
→ if文の処理の中にif文を入れることを入れ子(ネスト)という、より複雑な処理ができるがコードが読みにくい欠点がある
```:例
整数型：A, B
A ← -135

if (Aが0以上)
  if ((A mod 2)が0と等しい)
  　"正の偶数"と出力
   else
     "正の奇数"と出力
   endif
elseif ((A mod 2)が0と等しい)
　"負の偶数"と出力
else
  "負の奇数"と出力
endif

⇒ 負の奇数と出力される
```
