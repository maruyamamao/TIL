## while文
→ 繰り返し処理をしたい時に使用する
→ 継続条件の評価を行った後に処理を行うので、**前判定繰り返し処理**という
```
while(継続条件)
  継続条件が成立している間、繰り返す処理
endwhile
```
```:処理の流れ
整数型：  a ← 1
while(aが5以下)
  aを出力
  a ← a + 1
endwhile

・ 1回目の判定が(aが1)trueなので、ループ内の処理を実行
⇒ 1を出力して、aが2に更新されて、判定へ戻る

・ 2回目の判定が(aが2)trueなので、ループ内の処理を実行
⇒ 2を出力して、aが3に更新されて、判定へ戻る

・ 3回目の判定が(aが3)trueなので、ループ内の処理を実行
⇒ 3を出力して、aが4に更新されて、判定へ戻る

・ 4回目の判定が(aが4)trueなので、ループ内の処理を実行
⇒ 4を出力して、aが5に更新されて、判定へ戻る

・ 5回目の判定が(aが5)trueなので、ループ内の処理を実行
⇒ 5を出力して、aが6に更新されて、判定へ戻る

・ 6回目の判定が(aが6)falseなので、ループを抜ける
⇒ aには6が格納されている
```

→ ループに入る前、継続条件がfalseになっている場合、**ループ内の処理は1回の実行されない**
```:継続条件がすでにfalseの場合
整数型： b ← 10
while(bが10より小さい)
  b ← b + 1
endwhile

⇒ bに10が格納されている
⇒ 1回もループ処理は行われない
```

## do while文
→ while文と似ているがdo while文は処理を実行してから継続条件の評価を行う、**後判定繰り返し処理**という
```
do
  継続条件が成立している間繰り返す処理
while
```
```:処理の流れ
整数型：  a ← 1
do
  aを出力
  a ← a + 1
while(aが5以下)

・ 1を出力して、aが2に更新されて、判定に行く
⇒ 1回目の判定が(aが2)trueなので、ループを継続する

・ 2を出力して、aが3に更新されて、判定に行く
⇒ 2回目の判定が(aが3)trueなので、ループを継続する

・ 3を出力して、aが4に更新されて、判定に行く
⇒ 3回目の判定が(aが4)trueなので、ループを継続する

・ 4を出力して、aが5に更新されて、判定に行く
⇒ 4回目の判定が(aが5)trueなので、ループを継続する

・ 5を出力して、aが6に更新されて、判定に行く
⇒ 5回目の判定が(aが6)falseなので、ループを抜ける
⇒ aには6が格納されている
```

→ ループに入る前、継続条件がfalseになっている場合でも、少なくとも**1回はループ内の処理を行う**
```:継続条件がすでにfalseの場合
整数型：  b ← 10
do
  b ← b + 1
while(bが10より小さい)

⇒ bには11が格納されている
⇒ 少なくとも1回は処理されてる
```
