## 管理会計
→ 経営者が経営の意思決定(企業活動の見直し、経営計画の策定)を行うために、部門別、製品別に財務計算や損益計算を行い、管理する会計手法

## 経営分析
→ 取引情報(伝票)の記録から決裁書の作成までのプロセスを理解し、企業活動の結果である決算書を読んで経営内容を判断すること
### 財務指標
→ 経営分析で利用する、決算書の勘定科目間の関係(割合)で示される指標のこと
#### 収益性指標
- 企業がどれだけ効率よく利益を上げているか、収益面から分析するための財務指標
##### ROE(Return On Equity： 自己資本利益率)
→ 自己資本に対する当期純利益の割合
→ ROE = 当期純利益 ÷ 自己資本
##### ROA(Return On Asset： 総資産利益率)
→ 総資産(= 他人資本 + 自己資本 = 総資本 )に対する当期純利益の割合
→ ROA = 当期純利益 ÷ 総資産

#### 採算性指標
- 投資効果を示す財務指標
##### ROI(Return On Investment： 投資利益率)
→ 投資額に対する私益の割合
→ ROI = 利益 ÷ 投資額

#### 安全性指標
- 経営活動に必要な資産の運用が健全かどうか、支払能力は十分かなど財政状態を分析するための財務指標
##### 自己資本比率
→ 長期的・潜在的な支払能力を示す指標で、比率が高いほど経営内容が安全といえる
→ 自己資本比率 = 自己資本 ÷ 総資本
##### 流動比率
→ 当座の支払能力を示す指標で、この比率が高いほど資金繰りが容易、経営内容は安全といえる
→ 流動比率 = 流動資産 ÷ 流動負債

### 経済性計画(経済性分析)
→ 意思決定の際に、複数の候補案の中から経済的に最も有利な案を選択する観点で行われる経営分析
#### 投資利益率法(ROI法： Return On Investment)
→ ROI(投資利益率)で判断する手法
#### 正味現在価値法(NPV法： Net Present Value)
→ 投資額と投資回収額の現在価値と比較して判断する手法

## 損益分岐点分析
→ 営業利益が0となる損益分岐点を把握して、利益計画などに役立てる分析手法
### 利益計画
→ 将来の一定期間に必要とされる利益目標を設定し、その目標を達成するための経営活動計画のこと
### 直接原価計算
→ 利益計画で利用される原価管理の方法
#### 固定費
→ 売上高や生産量とは関係なく発生する、一定の費用のこと
##### 固定費率
→ 売上高に対する固定費の割合
→ 固定費率 = 固定費 ÷ 売上高 
#### 変動費
→ 売上高や生産量に応じて増減する費用のこと
##### 変動費率
→ 売上高に対する変動費の割合
→ 変動費率 = 変動費 ÷ 売上高  

### 限界利益(貢献利益)
→ 固定費を回収できる利益(利益 + 固定費)のこと
→ 限界利益 = 売上高 - 変動費 = 営業利益 + 固定費 → 営業利益 = 限界利益 - 固定費
#### 限界利益率
→ 売上高に対する限界利益の割合、限界利益率と変動費率を加算すると1になる
→ 限界利益率 = 限界利益 ÷ 売上高 = 1 - 変動費 ÷ 売上高 → 限界利益率 + 変動費率 = 1

### 損益分岐点売上高
→ 損益分岐点における売上高のこと
→ 損益分岐点売上高 = 固定費 ÷ 限界利益率
