## if文
→ 条件によって処理を行う
### ブロック
→ 複数の処理を行うときに``{}``を使用する

```c#:例
int a = 5;
if(a % 2 == 0)
{
  Console.WriteLine($"{a}は偶数です。");
}
else
{
  Console.WriteLine($"{a}は奇数です。");
}
```
```html:出力
5は奇数です。
```

## else if文
→ 複数の条件のどれに当てはまるかによってそれぞれちがう処理を行いたい場合に使用
```c#:例
int num = 15;

if (num >= 0 && num <= 9)
{
  Console.WriteLine("1桁の数です。");
}
else if(num >= 10 && num <= 99)
{
  Console.WriteLine("2桁の数です。");
}
else if (num >= 100 && num <= 999)
{
  Console.WriteLine("3桁の数です。");
}
else
{
  Console.WriteLine("4桁以上です。");
}
```
```html:出力
2桁の数です。
```
## if文のネスト
→ if文の中にif文を入れ子(ネスト)することができる
```c#:例
int num = 100;
if (num > 80)
{
  if (num == 100)
  {
    Console.WriteLine("満点です。");
  }
  else
  {
    Console.WriteLine("もう少しです。");
  }
else
  {
  Console.WriteLine("がんばりましょう。");
  }
}
```
```html:出力
満点です。
```
