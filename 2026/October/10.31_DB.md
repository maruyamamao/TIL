## データベースの操作

### SELECT 列を取り出す
```HTML:SELECT構文
SELECT 列名1、列名2・・・
FROM   表名
```
全ての列を取り出すには＊(アスタリスク)を指定する
```HTML:SELECT * 構文
SELECT *
FROM   表名
```

### AS 列に別名をつける
```HTML:AS構文
SELECT 列名1 AS 別名、列名2 AS 別名・・・
FROM   表名
```

### 列の値を演算する
演算記号は+ - * /
```HTML:演算構文
SELECT 列名1 * 10, 列名2 - 200・・・
FROM   表名
```

### DISTINCT 重複を排除する
列の重複データを１つにまとめる
※SELECTの後ろにDISTINCTを指定する
```HTML:DISTINCT構文
SELECT DISTINCT 列名1、列名2・・・
FROM   表名
```

### WHERE 条件で絞り込む
行方向にデータを取り出す、条件を付けて検索する
```HTML:WHERE構文
SELECT 列名1、列名2・・・
FROM   表名
WHERE  条件
```

### BETWEEN ~ AND ~   (○○以上○○以下)
指定した範囲に合致するものを取り出す
```HTML:BETWEEN ~ AND ~ 構文
SELECT 列名1、列名2・・・
FROM   表名
WHERE  列名 BETWEEN ○○ AND ○○
```
