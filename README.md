# TIL - Today I Learned 📚

日々の学習で得た知識や気づきをアウトプットするためのリポジトリです。

プログラミングやIT技術を中心に、学んだこと・調べたこと・試したことなどを
自分の言葉で整理して記録しています。

---

## 📖 TILとは？

**TIL（Today I Learned）** は「今日学んだこと」という意味です。

このリポジトリでは、学習した内容をそのままにせず、

> 学ぶ → 理解する → 自分の言葉でまとめる → アウトプットする

という流れを意識して記録しています。

---

## 🎯 目的

- 学んだことを自分の言葉で整理する
- 後から見返せる学習記録を作る
- 理解が曖昧な部分を見つける
- 継続的な学習習慣を身につける
- GitHubで学習の積み重ねを可視化する
